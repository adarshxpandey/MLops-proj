👋 About This Project

This is a production-style ML system demonstrating data pipelines, model deployment, analytics, and monitoring.

Features

  • End-to-end ML deployment
  • Backend engineering with FastAPI
  • MLOps fundamentals
  • Data systems design
  • Real-time weather integration
  • Analytics dashboard

Tech Stack

  • Backend: FastAPI, Python
  • ML: scikit-learn, pandas, joblib
  • Database: SQLite
  • Frontend: Vanilla JavaScript, HTML/CSS
  • APIs: OpenWeatherMap

Model Details

  • Algorithm: Random Forest Regressor
  • Dataset: Bengaluru House Prices (Kaggle)
  • Features: Area, BHK, Bathrooms, Location
  • Target: House Price (in Lakhs)
